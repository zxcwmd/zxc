# Bloom Client

Bloom Client — настольный лаунчер Minecraft на **Electron + React + TypeScript**. Главное меню — заново нарисованная сцена Cherry Grove на закате: костёр и тёплая каменная площадка слева, посаженная у огня 3D-модель игрока в ракурсе три четверти и четыре круглых раздела. Кнопка «Играть» открывает отдельную настройку версии Minecraft, загрузчика и сборки. В desktop-режиме клиент управляет изолированными профилями и Modrinth modpacks, проходит официальную авторизацию и скачивает нужные файлы при первом запуске. Renderer не получает доступ к Node.js: системные действия доступны через ограниченный IPC API в Electron main process.

## Запуск

Требуются Node.js 22 и npm.

```bash
npm ci
npm run dev
```

Vite откроет web preview на `http://localhost:5173`. Это только интерфейс: браузерный preview не может авторизовать аккаунт, менять файлы компьютера или запускать Minecraft.

Для реального лаунчера запустите desktop-версию:

```bash
npm run desktop:dev
```

## Windows x64 installer

На Windows 10/11:

```bash
npm ci
npm run dist:win
```

`.exe` появится в `release/`. GitHub Actions workflow **Bloom Client Windows build** собирает Windows x64 NSIS installer. [Скачать актуальный установщик Bloom Client 0.5.12 Preview 1](https://github.com/zxcwmd/zxc/releases/download/v0.5.12-preview.1/Bloom-Client-Setup-0.5.12-x64.exe).

## Функции desktop-версии

- **Установка и запуск Java Edition.** Официальный version manifest Minecraft, релизы, snapshots, старые Beta и Alpha. При первом запуске EML Lib загружает файлы игры, подходящую Java Runtime и выбранный загрузчик. Поддерживаются Vanilla, Fabric, Quilt, Forge и NeoForge; несовместимые сочетания версий и загрузчика отклоняются.
- **Профили игры.** Изолированные каталоги, разные версии и загрузчики. Удаление профиля из Bloom не удаляет файлы игры или миры.
- **Аккаунты.** Microsoft-вход с проверкой владения Minecraft: Java Edition. Ely.by — только для аккаунтов и серверов, явно поддерживающих Ely.by; клиент использует официальный Ely.by authserver и authlib-injector. Nick-only/offline-вход не реализован.
- **Защита учётных данных.** Пароль Ely.by передаётся authserver по HTTPS только во время входа и не сохраняется; можно указать TOTP-код. Сессионные токены сохраняются только в зашифрованном через Electron `safeStorage` хранилище ОС (Windows DPAPI, macOS Keychain или Linux keyring). Если шифрование недоступно либо Linux использует небезопасный `basic_text` backend, аккаунт остаётся в памяти до закрытия лаунчера.
- **Modrinth.** Поиск модов и ресурс-паков с фильтрами по проекту, версии Minecraft, загрузчику и категории. Совместимость файлов проверяется перед установкой; SHA-512/SHA-1 проверяется по данным Modrinth. Доступен импорт локальных `.jar` (моды) и `.zip` (ресурс-паки), просмотр и удаление добавленных файлов.
- **Готовые сборки.** В разделе «Сборки» доступны профили Bloom и каталог Modrinth modpacks. `.mrpack` устанавливается в отдельный профиль: проверяются версия/загрузчик, HTTPS-источники, размеры и контрольные суммы; копируются `overrides` и `client-overrides`. Недоступные для автоматической загрузки файлы отмечаются для ручного добавления.
- **Скины и 3D-модель.** Главное меню показывает скин аккаунта (или demo-модель) в сидячей позе с опорой на руки, с ракурсом три четверти и естественным положением у костра; модель дышит и иногда осматривается. Её можно вращать перетаскиванием без zoom; через 3 секунды после отпускания она плавно возвращается к исходному направлению. На странице скинов есть 3D-предпросмотр skinview3d, предпросмотр локального PNG и официальная загрузка Java-скина в Microsoft-профиль. Для Microsoft принимаются PNG 64×64 или 64×32; для Ely.by загрузка открывает страницу провайдера.
- **Производительность.** Bloom записывает поддерживаемые параметры видео в `options.txt` выбранного профиля; Minecraft применяет их при следующем запуске.
- **HUD / PvP-визуал.** Визуальные параметры сохраняются в `config/bloom-client-hud.json`. Этот репозиторий пока не содержит игрового Bloom HUD-мода, поэтому сами оверлеи (keystrokes, CPS, броня и т. п.) в игре ещё не отображаются. Это честно отмечено в интерфейсе; Bloom не внедряет читы и не показывает игроков через блоки.

## Архитектура и безопасность

- `electron/main.cjs` выполняет файловые операции, безопасное хранение токенов, вход, Modrinth-загрузки и запуск Minecraft.
- `electron/preload.cjs` предоставляет renderer только узкие типизированные IPC-вызовы.
- `src/` содержит React UI. Browser preview работает без desktop API и явно отключает файловые операции.
- Minecraft запускается через `eml-lib` (MIT); 3D-предпросмотр скинов использует `skinview3d` (MIT). Режимы offline/cracked auth не вызываются и не представлены в UI.
- Ely.by предназначен только для совместимых серверов. Microsoft-вход и владение Java Edition требуются для обычной официальной игры и premium-серверов.
