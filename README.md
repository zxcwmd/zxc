# NEXUS — Minecraft launcher UI prototype

Русскоязычный MVP на **TypeScript + React + Vite**, который можно запускать в браузере или упаковать в Windows desktop-приложение на Electron. Сборка выпускает установщик `.exe` для Windows x64.

## Быстрый запуск в браузере

```bash
npm ci
npm run dev
```

Открой адрес Vite, обычно `http://localhost:5173`.

## Запуск desktop-версии для разработки

```bash
npm ci
npm run desktop:dev
```

## Сборка Windows `.exe`

На Windows 10/11 с Node.js 22:

```bash
npm ci
npm run dist:win
```

Установщик появится в `release/`, например `NEXUS-Launcher-Setup-0.2.0-x64.exe`. Также workflow **Windows desktop build** собирает установщик на Windows runner GitHub Actions; EXE можно скачать из раздела Artifacts соответствующего запуска. Его можно запустить вручную через **Actions → Windows desktop build → Run workflow**.

## Что уже работает

- Экраны «Главная», «Сборки», «Автоматизация» и «Настройки».
- Смена профиля, параметры и переключатели автоматизаций сохраняются локально.
- Параметры автоматизаций можно экспортировать в JSON.
- Electron-оболочка с изолированным renderer-процессом; Vite остаётся доступен для browser preview.

## Ограничения и безопасность

Это пока UI-прототип: он **не скачивает и не запускает Minecraft**, не реализует Microsoft OAuth и не исполняет игровые автоматизации. Я не добавляю обход лицензии, авторизации или DRM. Для игры через лаунчер потребуется официальный Microsoft-вход, проверка/установка Java и получение игровых файлов из официальных источников. Экспортируемый JSON — только конфигурация для совместимых модов; используйте автоматизации только в одиночной игре или там, где они разрешены правилами сервера.
