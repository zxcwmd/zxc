# NEXUS — Minecraft launcher concept

Интерактивный русскоязычный MVP интерфейса лаунчера на **TypeScript + React + Vite**. Макет рассчитан на будущую desktop-оболочку Electron/Tauri; текущая версия запускается в браузере.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки: `npm run build`.

## Что уже работает

- Переключение экранов «Главная», «Сборки», «Автоматизация» и «Настройки».
- Смена выбранного профиля игры, настройки и переключатели автоматизаций сохраняются в `localStorage`.
- Настраиваемые параметры профилей автоматизации и экспорт текущего профиля в JSON.
- Адаптивная тёмная панель с оригинальным voxel-артом.

## Важно

Это браузерный UI-прототип: он **не скачивает и не запускает Minecraft**, не выполняет вход Microsoft и не внедряет игровые моды. Переключатели автоматизаций формируют настройки для будущего адаптера/совместимых модов. Для полноценного desktop-запуска нужны безопасная Electron/Tauri-оболочка, официальный Microsoft OAuth, проверка/установка Java и загрузка файлов игры из официальных источников. Используйте игровые автоматизации только в одиночной игре или там, где они явно разрешены правилами сервера.
