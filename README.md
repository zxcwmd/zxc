# Bloom Client — Minecraft launcher UI prototype

Русскоязычный MVP на **TypeScript + React + Vite + Electron** с iOS-inspired Liquid Glass интерфейсом. Можно запускать в браузере или упаковать в Windows desktop-приложение; сборка выпускает установщик `.exe` для Windows x64.

## Быстрый запуск в браузере

```bash
npm ci
npm run dev
```

Открой адрес Vite, обычно `http://localhost:5173`.

## Запуск desktop-версии для разработки

```bash
npm ci
npm run desktop:dev
```

## Сборка Windows `.exe`

На Windows 10/11 с Node.js 22:

```bash
npm ci
npm run dist:win
```

Установщик появится в `release/`, например `Bloom-Client-Setup-0.3.0-x64.exe`. Также workflow **Bloom Client Windows build** собирает установщик на Windows runner GitHub Actions; EXE можно скачать из раздела Artifacts соответствующего запуска. Его можно запустить вручную через **Actions → Bloom Client Windows build → Run workflow**.

## Что уже работает

- Экраны «Главная», «Сборки», «Автоматизация» и «Настройки».
- Смена профиля, параметры и переключатели автоматизаций сохраняются локально.
- Параметры автоматизаций можно экспортировать в JSON.
- Liquid Glass: матовое стекло, мягкие анимации, градиентные свечения и адаптивная вёрстка.
- Экран выбора Microsoft / Ely.by; в текущей версии это только UI, реальная авторизация не подключена.
- Electron-оболочка с изолированным renderer-процессом; Vite остаётся доступен для browser preview.

## Ограничения и безопасность

Это пока UI-прототип: он **не скачивает и не запускает Minecraft**, не реализует Microsoft OAuth или Ely.by auth и не исполняет игровые автоматизации. Вход только по нику/обход авторизации не поддерживается. Ely.by можно подключать только для аккаунтов и серверов, которые явно используют этот провайдер; в текущей сборке интеграция не включена. Я не добавляю обход лицензии или DRM. Для официальной игры нужны Microsoft-вход, Java и файлы из официальных источников. Экспортируемый JSON — только конфигурация для совместимых модов; используйте автоматизации только в одиночной игре или там, где они разрешены правилами сервера.
